# REDA menswear demo

Static demo with a local MediaPipe pose and clothing segmentation preview.
The browser processes user photos locally; no photo upload API is included.

Publish the main branch root with GitHub Pages. Open the site over HTTPS,
then use #tryon. All image, module, WASM and model paths are relative.
No Python server is required for the published static site.

The try-on is an approximate visual overlay, not a validated fit measurement.
Product 68 has an unavailable-image placeholder and is excluded from try-on.
